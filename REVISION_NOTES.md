# Revision notes: paper 2, "Restoring Native CT Evidence at Fixed Proposals for Lung Nodule Ranking"

Baseline: v6 source as received (first commit `53747d0`). No supervisor comments were provided for this paper, so the group's standing revision checklist was applied.

## Length and format
- **Length decision (group):** the CVPR 2027 guidelines state an 8-page limit for the main text, with only references and the LLM Usage Statement allowed to go beyond it. A first pass fit 8 pages. The group then said the paper may go beyond 8 pages, so the main text now runs into page 9: the conclusion ends partway down page 9, followed by the LLM statement and references (10 PDF pages in total). The material added for this (marked "added in the 9-page pass" below) sits in separable blocks if it has to be cut back later.
- `main.tex` and `supplement.tex` both compile on their own (`latexmk -pdf`), locally and on Overleaf.
- One command rebuilds everything: `./scripts/make_all.sh`.

## Open items for the group
1. **Fit-2 attention heads did not train (needs a rerun).** For seed 9143, the direction-blind heads at widths 48 and 96 and the direction-aware head at width 96 selected their first checkpoint (epoch 4), and their CPM equals the frozen ball scorer exactly (0.8283). The v6 text read their contrasts as evidence about geometry and width; for example, the "width-96 gap of +4.21" is just band versus ball. The revision states this openly in Sec. 5.3, the figure, the limitations and supplement Sec. S4. **Suggested experiment:** retrain these three heads (for example with a nonzero-init last layer, a higher learning rate, or selection that excludes epoch 4), or report results from a third seed.
2. **Verify the 14 new references** at the end of `references.bib`.
3. **LLM statement:** a sentence about this revision (Claude) was added. Check the whole statement, including "study design", against the CVPR 2027 policy.
4. **Repo visibility:** this GitHub repo is public under a named account and has the paper's exact title, which can break double-blind review. Consider making it private until decisions come out.
5. **Optional new experiments that would strengthen the paper:**
   - a second seed for the native-source arm and for the single-stream network (each currently has one);
   - a coverage-versus-continuity control: the same number of visible exterior voxels as the native-source arm, but contiguous (for example a thinner band), to separate the two explanations in Sec. 5.2;
   - FROC bootstrap bands for Fig. 3b (only point curves are in the aggregate);
   - a few qualitative examples (gained and lost lesions with ball/band crops) for a figure, if patient-image display is allowed.
